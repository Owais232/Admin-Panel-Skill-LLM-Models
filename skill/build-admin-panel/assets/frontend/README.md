# Admin panel template

Generated by `build-admin-panel`. A complete, client-only Next.js 15 admin
panel: auth with a single-flight token-refresh queue, persisted session, app
shell, dashboard, one worked entity page, and a browser verification harness.

```bash
npm install
npm run dev          # http://localhost:3001
npm run typecheck
npm run verify       # needs ADMIN_EMAIL + ADMIN_PASSWORD
```

## Adapt these four things first

Nothing works until the first two match the real backend.

| # | File | What to change |
|---|---|---|
| 1 | `src/types/index.ts` + `src/lib/api.ts` | `ApiEnvelope` and the unwrap helpers, against the **interceptor source** |
| 2 | `src/services/auth.ts` | Login field (`email` vs `identifier`), and whether `deviceId`/`platform` are expected |
| 3 | `.env.local` | `NEXT_PUBLIC_API_URL`, and add this origin to the backend's CORS list |
| 4 | `src/lib/branding.ts` + `src/app/globals.css` | Name, copy, and the primary hue |

A wrong envelope does not error, lists render and pagination silently never
works. Verify one endpoint with `curl` first.

## Adding an entity

Copy the `users` trio and adjust:

- `src/services/users.ts`: query hooks, mutations, one `invalidate()` helper
- `src/app/(dashboard)/dashboard/users/page.tsx`: filters, columns, table
- `src/components/users/user-detail-dialog.tsx`: detail rows and actions

Then add it to `src/components/app-shell/sidebar.tsx` and to `PAGES` in
`verify.js`.

```
│   └── layout.tsx
├── components/
│   ├── ui/                  owned Radix wrappers, edit freely
│   ├── app-shell/           sidebar + topbar
│   ├── data-table.tsx       generic table w/ skeleton, empty state, paging

│   ├── stat-card.tsx, page-header.tsx, status-badge.tsx
├── lib/
│   ├── api.ts               axios, refresh queue, unwrap helpers, clean()
│   ├── auth-store.ts        zustand + persist, `hydrated` flag
│   ├── branding.ts          every product-specific string
│   └── utils.ts             cn + formatters
├── services/                one file per entity
└── types/                   envelope + entity types
```

## Two things that will bite

**Stop the dev server before `npm run build`.** Building alongside a running
dev server corrupts its cache; the page then returns 200 while every chunk
404s, and the panel hangs on "Loading…" exactly like a broken auth guard.

**Add this origin to backend CORS.** A login form that does nothing on submit
while `curl` against the same endpoint works is a missing
`Access-Control-Allow-Origin`, note the preflight still returns 204, so the
status code alone tells you nothing.
